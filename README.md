# Bike Sales Analysis Using Excel

## Project Overview
This project analyzes bike purchase data using Microsoft Excel to explore customer demographics and purchasing patterns. It was completed as a hands-on learning project based on a tutorial by Alex The Analyst.

## Objectives
- Clean and prepare the dataset for analysis.
- Explore customer demographics and bike purchasing behaviour.
- Summarize data using PivotTables.
- Create visualizations and an interactive dashboard to present findings.

## Tools Used
- Microsoft Excel
- Excel formulas and data cleaning techniques
- PivotTables and PivotCharts
- Interactive dashboard elements

## Project Files
- `Bike purchase.xlsx` — Excel workbook containing the project analysis.

## Learning Outcomes
- Practised preparing data for analysis.
- Improved skills in summarizing and visualizing data.
- Learned to present business insights through an Excel dashboard.
